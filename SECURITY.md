# Security

Do not post credentials or vulnerability details in public issues. Use **Security → Report a vulnerability** on the affected repository when private vulnerability reporting is enabled. Otherwise, contact [Favour Anifowose](https://github.com/favorstic) through a private contact channel listed on that profile; share sensitive details only after establishing a private channel.

The latest `v1` release receives security fixes. Callers should use the maintained major tag and review workflow updates. Deployments require narrowly scoped credentials and protected GitHub environments; production environments must require Favour's approval and restrict deployments to `main`. Report a leaked credential privately and revoke it promptly in the issuing service.
